# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Badya, please do not disclose it publicly via GitHub issues.
Instead, report security concerns responsibly by contacting the maintainers directly or creating a private security advisory on GitHub.

We will review reports promptly and publish patches accordingly.
